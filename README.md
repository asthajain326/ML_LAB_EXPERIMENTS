# Machine Learning Lab Experiments

This repository contains the Machine Learning laboratory experiments completed as part of my **Bachelor of Technology (Computer Science Engineering)** curriculum.

The experiments cover the complete machine learning workflow, including data visualization, data preprocessing, regression, classification, and model evaluation using Python and Scikit-learn.

The primary objective of these experiments is to understand how different machine learning algorithms work by implementing them on real-world and synthetic datasets.

---

# About this Repository

This repository demonstrates practical implementation of fundamental Machine Learning concepts using Python.

Each experiment focuses on solving a specific machine learning task such as:

- Data Visualization
- Data Cleaning & Preprocessing
- Linear Regression
- Multiple Linear Regression
- Logistic Regression
- Naïve Bayes Classification

The experiments include data loading, preprocessing, feature engineering, model building, prediction, visualization, and evaluation.
